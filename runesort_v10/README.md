RUNE v10 scratch experiment (unmerged, proprietary). Based exactly on frozen v7. Only fixed_radix and dense_radix scratch allocation is changed from std::vector value-initialized storage to std::unique_ptr<uint64_t[]>(new uint64_t[n]), which leaves uint64 storage default-initialized. Stable histogram scatter writes every destination slot once per pass before that buffer is read, so this avoids redundant initialization without changing the output. Local five-seed v5 mechanism-only benchmarks showed inconsistent improvements; CI must directly test the v7-derived candidate on ARM64 and x86 at 1M/4M keys. No SOTA/novelty claim; do not merge without evidence.
